# next-steps

Adds a system prompt section so Claude ends substantial answers with two or three concrete next steps you could hand it.

## Install

`/plugin install next-steps --marketplace igorturcanu/cistig`, or Copy this folder into your mods folder, or load it for a session with `claude --plugin-dir ./mods/next-steps`. It hot-reloads when its files change. Check it with `claude plugin validate ./mods/next-steps`.

## Remove

Delete the folder, or stop passing `--plugin-dir`. The mod keeps no data of its own.
